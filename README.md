# НФП-Калькулятор

Приложение для оценки уровня физической подготовленности и ведения дневника тренировок. Подходит для спортсменов, инструкторов и всех, кто следит за своими физическими показателями.

## Возможности

- 📊 **Точный расчёт:** Автоматический подсчёт баллов и итоговой оценки по официальным таблицам нормативов.
- 👤 **Личный профиль:** Учёт возраста, пола и категории для подбора правильных нормативов.
- 🎯 **Гибкая настройка:** Формируйте свой комплекс упражнений для проверки.
- 📈 **История и статистика:** Ведите дневник сдач, смотрите графики прогресса и личные рекорды.
- 🏋️ **Создание тренировок:** Создавайте собственные тренировки с таймером и делитесь ими с друзьями.
- ☁️ **Синхронизация:** Тренировки и лайки синхронизируются через iCloud (CloudKit).
- 🥇 **Рейтинг:** Лучшие тренировки поднимаются в топ по количеству лайков.

## Технологии

- SwiftUI + SwiftData (для истории и профиля)
- CloudKit (Public Database) для тренировок и лайков
- MVVM (Observable)
- iOS 17+
