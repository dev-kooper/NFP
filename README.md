# NFPCalc — Калькулятор НФП

Приложение для оценки физической подготовленности военнослужащих в соответствии с Приказом Министра обороны РФ № 230 от 20.04.2023.

## Возможности

- 📊 Расчёт баллов и оценок по ПМО №230 (схемы А и Б)
- 👤 Личный профиль (возраст, пол, категория, курс, количество упражнений)
- 🎯 Автоматический подбор нормативов под возрастную группу
- 📝 Редактирование КПК (какие упражнения сдавать в каждой группе)
- 📈 История сдачи комплексов с возможностью поделиться
- 🏋️ Создание собственных тренировок
- ☁️ Синхронизация тренировок и лайков через iCloud (CloudKit)
- 🥇 Рейтинг тренировок по лайкам пользователей

## Технологии

- SwiftUI + SwiftData
- CloudKit (Public Database)
- MVVM (Observable)
- iOS 17+
